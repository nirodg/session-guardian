# Project Overview

- Name: SessionGuardian
- Purpose: agent-agnostic project memory, session recovery, and scope protection for AI-assisted development. The project is the source of truth; the agent is replaceable.
- Intended users: developers using Claude Code, Codex, OpenCode, Cursor, Gemini CLI, Windsurf or other coding agents, often across many projects and terminals.
- Desired outcome / definition of done: every roadmap item (docs/ROADMAP.md) implemented, tested, documented, and verified on Linux, macOS and Windows.
- Current phase: v0.3.0 — all roadmap phases implemented on Linux; cross-platform verification pending.
- Last verified: 2026-11-19 (Linux, Python 3.9 and 3.12)
