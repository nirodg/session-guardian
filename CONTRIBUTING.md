# Contributing

Help make AI coding sessions recoverable and focused.

Principles: agent-neutral core; portable Markdown memory; safe, idempotent installation; never overwrite user instructions; evidence over assumptions; scope protection without blocking explicit user direction.

Before a PR: explain the problem, keep changes focused, test affected platforms/agents, update docs and compatibility claims, and exclude credentials or private project data.

New adapters must document install location, discovery, lifecycle hooks, upgrade behavior, and reproducible validation.
